A lightweight, low-latency message broker for high-throughput event streaming.  
- Achieve sub-millisecond end-to-end message delivery  
- Scale to millions of concurrent connections with minimal resource overhead  
- Support at-least-once, at-most-once, and exactly-once delivery semantics  
- Provide dynamic topic partitioning and automatic consumer rebalancing  
- Integrate native Protobuf and Avro schema validation
